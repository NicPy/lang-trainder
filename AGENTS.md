# AGENTS.md

## Project

Lang Trainder is an app for learning words. The user adds words they want to learn, then enters the app and takes quizzes on them.

## Core concepts

- **Word list**: words (with translations/definitions) added by the user.
- **Quiz**: a session that tests the user on words from their list.
